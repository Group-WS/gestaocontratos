# Funcionalidades

Descrição dos **fluxos** do produto: telas, passos, estados e permissões de cada funcionalidade.
Fluxo muda com frequência e pode ser alterado pelas tarefas; o que ele **não** pode é redefinir
regra de negócio — ele só cita as regras (`RN-NNN`) que usa, catalogadas em
`docs/regras-de-negocio/`.

Molde: `_template.md`. Padrão: `.quality/regras/02-regras-de-negocio.md` e
`.quality/regras/06-padroes-de-tela.md`.
